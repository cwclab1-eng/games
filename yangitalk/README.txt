양이톡 (Yang-i Talk) — 웹서버용 패키지
=====================================

이 폴더를 통째로 웹서버에 올리면 바로 실행됩니다.
(압축을 풀어 나온 파일을 그대로 업로드하세요)

■ 들어 있는 것
  index.html                        … 양이톡 메신저 본체 (이 주소로 접속)
  블록듀얼_2단계_온라인대전.html      … 게임 1 (2인 테트리스 온라인 대전)
  한판_맞고_2단계_온라인대전.html     … 게임 2 (2인 화투 맞고 · 뻑 3장 연출)
  Match3_낙하형_단독실행판.html       … 게임 3 (2인 3매치 온라인 대전)
  sw.js                             … 게임이 찾는 서비스 워커 자리 (지워도 동작, 404만 남음)

■ 사용법
  1) 브라우저에서 index.html 주소를 엽니다.
  2) 닉네임을 넣고 [시작하기] → 친구 탭에서 내 초대 코드(6자리)를 확인합니다.
  3) 그 코드나 초대 링크(...?room=내코드)를 가족·친구에게 보냅니다.
  4) 상대가 링크를 열고 닉네임만 넣으면 1:1 방이 열립니다.
  5) 대화방 + → 게임하기 → 게임 선택 → [방 만들고 초대하기]
     → 4자리 방 코드가 담긴 초대 카드가 대화방에 붙습니다.
  6) 상대가 카드의 [참여하기]를 누르면 코드 입력 없이 게임이 열립니다.

■ 서버 요구사항
  - 정적 파일만 있으면 됩니다. PHP·DB·Node 설치 불필요.
  - HTTPS 권장 (마이크/클립보드 등 브라우저 기능). 실시간 통신은 wss(443)라 HTTPS에서 문제 없습니다.
  - 한글 파일명이 깨지는 서버라면 파일명을 영문으로 바꾸고
    설정 → 게임 관리 → 주소 변경에서 새 경로를 지정하세요.
    (예: blockduel.html / match3.html)
  - 100MB 호스팅(우비 등)에서도 넉넉합니다 — 세 게임 파일 합계 약 11.7MB
    (Match3 5.9MB · 한판 맞고 5.6MB · 블록 듀얼 0.25MB, 2026-11-27 기준).

■ 게임 파일에 대해
  세 게임 파일에는 양이톡 초대 카드의 방 코드로 방을 여는 부트스트랩(?host=1)이
  몇 줄 들어 있습니다. 이 파라미터가 없으면 예전과 똑같이 동작하므로
  게임을 단독으로 열어 쓰는 데는 아무 영향이 없습니다.

■ 전체화면 · 뒤로가기 보호
  - 게임을 시작하면 자동으로 전체화면으로 들어가 주소장·하단 바가 숨는다.
    (브라우저가 거부하면 그냥 창 모드로 진행한다)
  - 양이톡에서 게임을 열 때는 앱 창 전체가 전체화면이 된다 — 위쪽 [대화방으로] 바는 그대로 보인다.
  - 게임 중 휴대폰 뒤로가기를 한 번 눌러도 판이 날아가지 않는다(일시정지 또는 안내 문구).
  - 다시 전체화면을 켜고 끄려면 게임 오른쪽 위 ⛶ 버튼(양이톡은 게임 바의 ⛶).

■ 대화는 어디에 저장되나요
  - 각자 브라우저(localStorage)에만 저장됩니다. 서버에 쌓이지 않습니다.
  - 실시간 전달은 공개 MQTT 브로커 4곳을 통해 브라우저끼리 직접 주고받습니다.
    (별도 서버·API 키 없음)
