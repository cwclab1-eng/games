      ⚙️ 게시판 연결

      실시간 공유 (Firebase Realtime Database)

      주소를 넣으면 이 게시판에 쓴 글이 방문자 모두에게 실시간으로 보입니다. 비워 두면 이 폰에만 저장돼요.

      Firebase 준비 방법 (3분)
      1. console.firebase.google.com → 프로젝트 만들기
      2. 빌드 → Realtime Database → 데이터베이스 만들기 → 위치 선택 → 테스트 모드로 시작
      3. 데이터 탭 위에 나오는 주소(…firebaseio.com 또는 …firebasedatabase.app)를 복사해 위 칸에 붙여넣기
      4. 규칙(Rules)이 아래처럼 되어 있어야 누구나 읽고 쓸 수 있어요
      { "rules": { ".read": true, ".write": true } }
      Firebase 콘솔 열기

      공개 게시판이라 누구나 읽고 쓸 수 있습니다. 비밀번호 · 개인정보는 올리지 마세요.
